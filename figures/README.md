# Figures

Generated figures are grouped by semantic manuscript role and licensed CC BY 4.0. `main/` contains the selected publication assets, `supplementary/` contains supplementary outputs, and `archive/` preserves distinct unselected variants. LaTeX placement, rather than a filename prefix, determines the displayed figure number. Each selected final figure has a sidecar record or manifest entry containing input and output provenance. Prepared-data figures are included when their compact scientific inputs are complete; unavailable raw checkpoint-to-prepared-data stages are documented as a separate reproducibility boundary.
