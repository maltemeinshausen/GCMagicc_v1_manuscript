# Figures

Generated figures are grouped by semantic manuscript role and licensed CC BY 4.0. `main/` contains the selected publication assets, `supplementary/` contains supplementary outputs, and `archive/` preserves distinct unselected variants. LaTeX placement, rather than a filename prefix, determines the displayed figure number. Each selected final figure has a sidecar record containing input and output provenance. Nicolai-dependent figures remain omitted at release freeze unless their complete generator and foundational data bundle is available.
