# Figures

Generated figures are grouped by workflow and licensed CC BY 4.0. Each final figure has a sidecar JSON record containing input hashes and output hashes. `gcmagicc_workflow/` is a data-free vector schematic generated entirely by the release-native script; `turkiye_regional_application/` is generated solely from the frozen small-data bundle in this repository; `drought_common_protocol/` records the corrected drought and three-SMILE analysis, including the standalone seven-panel main synthesis. Nicolai-dependent figures are omitted at release freeze unless their complete generator and foundational data bundle is available.
